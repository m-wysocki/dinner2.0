# 13: Recipe ingredients

**What to build:** A user can add structured ingredients to a recipe and confirm or create their canonical identities.

**Blocked by:** 12: Basic recipe creation

**Status:** ready-for-agent

- [ ] User can select a system catalog ingredient.
- [ ] User can create a user-owned custom ingredient.
- [ ] User can edit name, quantity, unit, note, and order.
- [ ] Missing canonical identity blocks saving until corrected.
- [ ] Empty quantities are supported for expressions such as “to taste”.
