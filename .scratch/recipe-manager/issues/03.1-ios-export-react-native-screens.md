# 03.1: Unblock Expo iOS export (react-native-screens)

**What to build:** The Expo mobile app compiles and exports for iOS without a dependency/toolchain error.

**Blocked by:** 03: Mobile bootstrap and API client

**Status:** resolved

## Background

Follow-up from the code review of 03. Issue 03 was marked resolved even though its resolution notes: "Expo iOS export remains blocked by a `react-native-screens` dependency/toolchain compatibility error." The app runs through the workspace tooling (`expo start`) and tests pass, but the iOS export/build step fails.

## What to do

- Reproduce the iOS export/build error and capture the exact failure output.
- Identify the cause: a version conflict in `react-native-screens` against the pinned Expo/React Native/Xcode toolchain.
- Resolve it with the minimal dependency or toolchain change (e.g. pin/align `react-native-screens`, or upgrade Expo/React Native), without breaking the other mobile checks.
- Verify: `expo export` (or the documented iOS build command) succeeds, and mobile typecheck, tests, lint, and formatting still pass.

## Definition of done

- [x] iOS export/build succeeds locally.
- [x] The root cause is recorded in the resolution notes.
- [x] Mobile typecheck, tests, lint, formatting, and workspace test suite pass.

## Resolution

**Root cause:** version drift in the RN toolchain. `react-native-screens` was not a direct dependency, so pnpm resolved the `@react-navigation` peer range to the newest `react-native-screens@4.27.0`, whose `fabric/SearchBarNativeComponent.ts` uses codegen command types (`React.ComponentRef`) incompatible with the Expo SDK 54 / React Native 0.81 toolchain, failing Metro bundling with `The first argument of method blur must be of type React.ElementRef<>`. The same peer resolution also drifted `react@19.2.8`, `react-native@0.81.6`, and `@types/react@19.2.18` past the SDK 54 pins.

**Fix (align to Expo SDK 54's bundled native modules):**
- Added `react-native-screens@~4.16.0` and `react-native-safe-area-context@~5.6.2` as direct dependencies (`npx expo install`).
- Aligned `react-native@^0.81.5`, `react@^19.1.0`, `@types/react@^19.1.17`, and added `react-dom@19.1.0` (dev) to silence the web-tooling peer mismatch.
- Added `dist/` to `.prettierignore` so the export output does not fail `format:check`.

**Verified:** `expo export --platform ios` bundles successfully (1095 modules); mobile typecheck, lint, tests (9), workspace typecheck/lint/tests, and `format:check` all pass.
