# 04: User registration

**What to build:** A person can register with email and password and receive a pending application account.

**Blocked by:** 02: API bootstrap and Supabase configuration; 03: Mobile bootstrap and API client

**Status:** ready-for-agent

- [ ] Invalid registration data is rejected with safe, predictable errors.
- [ ] Supabase Auth registration is invoked by the API/application flow.
- [ ] A linked application user is created with `PENDING` access.
- [ ] The mobile UI presents success and failure states.
