# 11: Recipe domain and ingredient catalog

**What to build:** The application has the persisted recipe domain and a seeded catalog of canonical ingredients.

**Blocked by:** 10: Active access state

**Status:** ready-for-agent

- [ ] Recipes belong to application users.
- [ ] Recipe ingredients reference canonical catalog identities and retain name snapshots.
- [ ] Preparation steps have explicit order.
- [ ] Quantities use precise decimal storage and canonical units.
- [ ] Seeded system ingredients have Polish and English display names.
- [ ] Custom catalog entries can be owned by a user.
